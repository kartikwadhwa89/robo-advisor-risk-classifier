# Robo Advisor Risk Classifier

## 📌 Project Overview

This project explores how Artificial Intelligence and Machine Learning can be used in a robo-advisory platform to classify investors based on their risk profile.

The project uses machine learning classification models to predict investor risk categories and demonstrates how AI tools can support research, coding, and business analysis.

## 🎯 Business Problem

Robo-advisory platforms need to understand an investor's risk profile before providing suitable investment recommendations.

Manual risk assessment can be time-consuming and difficult to scale. A machine learning system can help classify investors based on relevant financial and personal attributes.

## 🤖 AI/ML Solution

The project uses classification algorithms to predict investor risk categories.

### Models Used
- Logistic Regression
- Decision Tree
- Random Forest

The models are trained and evaluated to understand how effectively they can classify investor risk profiles.

## 📊 Dataset

A synthetic dataset is used for the project.

The dataset represents investor-related information that can be used for risk classification, such as financial and demographic characteristics.

## ✍️ Prompt Engineering

### Basic Prompt

"Tell me how AI is used in robo-advisors."

### Improved Prompt

"Act as a fintech business analyst. Explain how AI and machine learning can be used for risk-profile classification in an Indian robo-advisory platform. Focus on the business problem, required data, suitable ML models, regulatory considerations and business benefits. Provide reliable sources and clearly separate verified information from assumptions."

### Why the Improved Prompt Was Better

The improved prompt provided:
- A specific role
- A clear business context
- A specific geographic and regulatory context
- Required areas of analysis
- A requirement for reliable sources

This resulted in a more focused and relevant response.

## 🔍 Fact-Checking & Critical Evaluation

AI-generated information was not accepted without verification.

Important regulatory and factual information was cross-checked using reliable sources such as official regulatory and research sources.

This helped identify information that was too generic, incomplete, or required further verification.

## 📈 Key Learning

This project demonstrated that:

- Good prompts produce more relevant AI outputs.
- AI can support both research and technical development.
- Machine learning can be applied to investor risk classification.
- AI-generated information should be fact-checked before being used.
- Human judgement and oversight remain important.
